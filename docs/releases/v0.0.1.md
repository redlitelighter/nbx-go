## NBX-go v0.0.1 — "GO" (beta)

**The next step.** First public beta of NBX-go: a self-custodial wallet for the Hedera ecosystem with GO, an assistant that runs entirely on your phone.

> ⚠️ Beta on Hedera **mainnet** — real funds. Start small. GO gives information, not financial advice.

### Highlights
- **Hedera-only wallet** — HBAR, USDT0, SAUCE, xSAUCE, PLEX (Lambdaplex), DOVU, DAVINCI, KARATE; built on Tether's WDK, keys encrypted on-device.
- **Swaps on SaucerSwap V2** — any pair, best route from live pools, native HBAR in/out, automatic token association, price-impact warnings, 0.03% platform fee.
- **Spot trading & limit orders** — live SaucerSwap charts; set a buy/sell price in USDT0 and the order fills when it's hit (while the app is open).
- **Earn** — SAUCE → xSAUCE staking with live APR.
- **GO assistant (offline, QVAC)** — buy, sell, swap, send, stake and set orders by chat; live balances and prices; chart-pattern reading (Head & Shoulders, Double Top/Bottom, Flags, Pennants, Triangles, Wedges); switchable text/vision/speech models.
- **QR scanning** for sending and contacts, HashScan-linked history, light/dark theme, beta terms on first run.

### Install
1. Download `NBX-go-v0.0.1.apk` below (arm64 Android, Android 10+).
2. Open it and allow installing from this source.
3. Create or import a wallet, then open GO and download its text model (382 MB, Wi-Fi recommended).

### Known limitations
- Android arm64 only; signed with a development key (not on Play Store yet).
- Limit orders only fill while NBX-go is open and unlocked.
- Selling PLEX is currently expensive: the HBAR/PLEX pool's liquidity is one-sided — the app warns when price impact exceeds 5%.
- Fiat on/off-ramps are coming soon.
