## NBX-go v0.0.2 — lighter GO (beta)

A much smaller download — same features as v0.0.1.

### What changed
- **Smaller APK.** Native libraries are now stored compressed (Android unpacks them once at install), and the wallet engine is Hedera-only: the unused Bitcoin, Spark, EVM-gasless and cross-chain protocol modules are gone (worklet bundle 37 MB → 4.5 MB).
- Build tooling: `npm run bundle:wdk` regenerates the wallet engine on any platform, including Windows.

### Install / upgrade
Download `NBX-go-v0.0.2.apk` below and open it. It installs over v0.0.1 — your wallet, contacts and downloaded GO models stay.

> ⚠️ Beta on Hedera **mainnet** — real funds. GO gives information, not financial advice.
