## NBX-go v0.0.5 (beta)

### Fixes
- **Balances load again.** Assets (Profile → Assets) showed "Failed" for every token: each balance was its own Hashio JSON-RPC call, and Hashio can take 5–11 s to answer, so the calls timed out. Balances now come from Hedera's mirror node in one sub-second request (HBAR and every token together).
- **Token icons in Assets.** SAUCE, xSAUCE, PLEX, DOVU, DAVINCI and KARATE showed as plain dark circles; they now use the bundled logos, in both themes.
- **Light theme.** The Models page (and any page using the shared page styles) went black in light theme; page backgrounds now always follow the theme.

### GO
- **Stop bar with countdown.** While GO works or listens, a pulsing stop button and a countdown sit above the input. Voice notes stop by themselves after 30 s; requests after 60 s (120 s for chart reading).
- **QR code screenshots.** The image button asks "QR code or price chart?". GO reads an address QR on the phone, then offers to send to it or save it as a contact.
- **Better conversation:** greetings, thanks and goodbyes; it always knows the day and time; app commands ("open settings", "take me to swap"); short answers to open questions (Hedera, HBAR fees, USDT0, swaps, staking, limit orders, safety, on-device AI) given one piece at a time — "tell me more" for the next; urgent messages (hacked, scammed, lost phone, wrong address) get the safety steps first; dead ends ("ok", "nah") get one short reply, then GO goes quiet; shorter advice.
- **NBX-go and NBX.** GO explains that NBX-go is a separate, independent wallet app — NBX support can't see or recover it.
- **Spoken HBAR.** "h-bah" (written by speech-to-text as "h bar", "age bar", "HBA"…) and "USDT zero" are understood as HBAR and USDT0.
