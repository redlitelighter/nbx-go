## NBX-go v0.0.4 (beta)

### Fixes
- **No more getting logged out by GO.** Attaching a chart screenshot, allowing the microphone or camera, and fingerprint confirmations open a system screen that briefly backgrounds the app — the auto-lock treated that as leaving and locked the wallet. Those prompts no longer lock it (leaving the app still does).
- **History page** rebuilt on Hedera's mirror node: token icons, contact names, All / Received / Sent and token filters, pull to refresh. It no longer waits on the WDK Indexer, which doesn't cover Hedera (checked: ethereum, arbitrum, avalanche, polygon, sepolia, tron, ton, bitcoin, spark only) and could leave the page loading forever.
- Send review no longer says Hedera sends are "Free" — every Hedera transaction pays a small HBAR fee.

### HBAR for fees
- Swap, Send, Earn and limit orders check your HBAR first: they block when there isn't enough for the network fee (or when an HBAR swap/send would spend the last of it) and warn when it's running low. GO's proposals carry the same warning.
- Out-of-HBAR errors now say so plainly: "Always keep some HBAR (at least 1) in your wallet."

### New
- **Log out** in Settings (locks the wallet; unlock with your password).
- **Models page** redesigned: one card per model type with a popover to pick the active model — sizes, trade-offs and "Downloaded" badges.
